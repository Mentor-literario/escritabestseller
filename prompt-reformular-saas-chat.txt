Reformule profundamente o SaaS Mentor Literário BestSeller.

A estrutura atual ainda está longe da visão desejada. Não quero uma plataforma com muitos módulos visíveis, nem uma página separada para Títulos, nem uma página chamada Minha Jornada.

A nova visão do produto é:

O Mentor Literário BestSeller deve ser, antes de tudo, um mentor em formato de chat.

A experiência principal do usuário deve acontecer na conversa com o Mentor BestSeller.

O Mentor conversa com o usuário, entende o momento dele, conduz a criação do livro por conversa e, quando cada parte fica pronta, salva os resultados dentro de Meus Livros.

O usuário não deve sentir que está preenchendo ferramentas. Ele deve sentir que está conversando com um mentor literário estratégico que conduz seu livro do zero até a publicação e vendas.

NOVA ESTRUTURA DA SIDEBAR:

A sidebar deve ser simples, curta e sofisticada.

Itens principais:

- Início
- Meus Livros

Recursos:

- Biblioteca BestSeller
- Planos
- Configurações

Não mostrar:
- Minha Jornada
- Títulos separado
- Gerador de Ideias
- Mapa do Livro
- Personagens
- Sinopse
- Autoria
- Amazon
- Autonomia
- módulos soltos

Todas essas funções devem existir dentro do fluxo do Mentor e dentro de cada livro salvo.

INÍCIO:

A página Início deve ser sempre o chat do Mentor BestSeller.

Título da página:
"Mentor BestSeller"

Subtítulo:
"Seu agente literário digital para transformar uma ideia em livro estruturado, publicável e com estratégia de venda."

A interface deve parecer um chat premium, tecnológico, elegante e envolvente.

Na primeira visita, o Mentor deve iniciar com uma mensagem como:

"Antes de te orientar de verdade, preciso entender o seu momento como autora. Vou te fazer algumas perguntas rápidas e, a partir disso, te ajudar a construir seu livro por partes."

O chat deve ter sugestões de respostas rápidas:

- Quero começar do zero
- Já tenho uma ideia
- Já comecei meu livro
- Meu livro está pronto
- Já publiquei, mas não vendo

Depois disso, o Mentor deve conduzir o diagnóstico.

DIAGNÓSTICO NO CHAT:

O diagnóstico deve acontecer dentro do chat, não em uma página separada de formulário grande.

O Mentor deve perguntar uma coisa por vez:

1. Como posso te chamar?
2. Você já escreve ou quer começar do zero?
3. Qual gênero literário você escreve ou quer escrever?
4. Em que fase está seu livro hoje?
5. Qual é sua maior dificuldade agora?
6. Você pretende publicar na Amazon?
7. Seu objetivo agora é concluir o livro, publicar ou vender mais?

Cada pergunta deve ter linguagem humana e explicação simples.

Exemplo:
"Como posso te chamar? Vou usar esse nome para personalizar nossas conversas e organizar seu projeto."

Quando o diagnóstico terminar, o Mentor deve mostrar um card de resultado:

"Seu diagnóstico literário está pronto"

Conteúdo:
- Nome
- Fase atual
- Gênero
- Maior dificuldade
- Objetivo principal
- Próximo passo recomendado

Botões:
- Salvar diagnóstico
- Continuar com o Mentor

O diagnóstico deve ser salvo no localStorage.

Depois do diagnóstico, o Mentor deve orientar a criação do primeiro livro.

Ele deve perguntar:

"Agora vamos criar seu primeiro projeto. Você já tem um título provisório para esse livro ou prefere deixar como 'Livro sem título' por enquanto?"

Opções:
- Tenho um título
- Ainda não tenho título
- Quero ajuda para criar títulos

Se o usuário escolher "Tenho um título", salvar esse título no livro atual.

Se escolher "Ainda não tenho título", criar o livro como "Livro sem título".

Se escolher "Quero ajuda para criar títulos", o Mentor deve conduzir uma conversa para gerar sugestões de título e permitir salvar o título escolhido dentro do livro.

MEUS LIVROS:

A página Meus Livros é a central onde todos os projetos do usuário ficam salvos.

A página deve mostrar uma lista de livros/projetos.

Nesta fase simulada, pode existir um livro principal salvo em localStorage, mas a interface deve estar preparada para múltiplos livros no futuro.

A página Meus Livros deve ter:

- botão "Criar novo livro"
- card para cada livro
- título do livro
- gênero
- fase atual
- última parte salva
- porcentagem de construção do projeto
- botão "Abrir livro"
- botão "Continuar com o Mentor"

Se ainda não houver livro salvo, mostrar:

"Você ainda não criou nenhum livro. Comece conversando com o Mentor BestSeller. Ele vai te ajudar a criar seu primeiro projeto."

Botão:
"Começar pelo Mentor"

DENTRO DE CADA LIVRO:

Ao clicar em "Abrir livro", o usuário deve ver o dossiê editorial daquele livro.

O título do livro deve aparecer no topo.

Exemplo:
"O Duque que Não Sabia Amar"

Abaixo do título, mostrar:
- gênero
- fase atual
- progresso do projeto
- última atualização
- botão "Continuar com o Mentor"
- botão "Editar título"

O dossiê do livro deve ser organizado em blocos ou abas:

1. Visão geral
2. Diagnóstico
3. Ideia
4. Premissa
5. Títulos
6. Sinopse
7. Personagens
8. Estrutura
9. Capítulos
10. Cenas
11. Publicação
12. Vendas

IMPORTANTE:
A área de Títulos não deve existir na sidebar.
Ela deve existir apenas dentro de cada livro, como uma parte do dossiê editorial.

Cada bloco deve puxar dados salvos durante a conversa com o Mentor.

Se algum bloco ainda não tiver dados, mostrar:
"Você ainda não construiu esta parte. Volte ao Mentor para continuar."

Botão:
"Continuar com o Mentor"

O dossiê deve parecer um arquivo editorial premium do livro, não uma ficha técnica fria.

TÍTULOS DENTRO DO LIVRO:

Dentro do bloco Títulos de cada livro, mostrar:

- título atual/favorito
- títulos sugeridos
- subtítulo, se houver
- justificativa estratégica
- tom do título
- força comercial percebida

Botões:

"Este livro ainda não tem um título definido. O Mentor pode ajudar você a criar opções mais fortes."

Botão:
"Criar títulos com o Mentor"

O usuário não escolhe módulos soltos. O Mentor conduz.

O Mentor deve ajudar o usuário a construir e salvar dentro do livro:

Quando o usuário responder, o Mentor deve gerar um resultado simulado estruturado.

Exemplo para Ideia:
