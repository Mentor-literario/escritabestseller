Crie uma plataforma SaaS completa chamada Mentor Literário BestSeller.

Não quero um MVP enxuto. Quero uma versão completa e navegável da plataforma, com todos os módulos essenciais para autores independentes escreverem, estruturarem, revisarem, publicarem e divulgarem seus livros.

Nesta primeira etapa, use dados simulados e funcionamento local, sem banco de dados real, sem pagamento real e sem IA real. Porém, a arquitetura deve estar preparada para receber Supabase, autenticação, pagamento e integração com IA posteriormente.

A plataforma deve unir duas funções principais:

1. Mentor conversacional com IA, chamado Mentor BestSeller.
2. Plataforma guiada por etapas, com módulos, checklists, formulários, entregáveis, progresso salvo e próximo passo recomendado.

O usuário deve sentir que está sendo conduzido por uma jornada completa:

Ideia → Estrutura → Personagens → Capítulos → Escrita → Revisão → Sinopse → Publicação → Lançamento → Vendas.

O SaaS será voltado para escritores iniciantes e autores independentes que desejam escrever, publicar e vender livros de ficção, principalmente romances comerciais, na Amazon KDP.

A promessa segura do produto é ajudar autores a construírem livros mais fortes, profissionais e com maior potencial de venda, sem prometer bestseller garantido, vendas garantidas ou ranking garantido.

Use a seguinte stack:

- Next.js
- TypeScript
- Tailwind CSS
- App Router
- Componentes reutilizáveis
- Estrutura preparada para Supabase futuramente
- Estrutura preparada para IA futuramente
- Estrutura preparada para pagamentos futuramente

Evite aparência infantil, colorida demais ou genérica de IA.
